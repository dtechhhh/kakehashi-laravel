# UI Documents

UI files are controlled read-only snapshots for Codex. Product, domain, schema,
API, security, and privacy documents remain higher authority.

- [DESIGN.md](DESIGN.md) — repository-local visual design system and shell reference.
- [UI_WIREFRAME_NOTES.md](UI_WIREFRAME_NOTES.md) — semantic UI authority below product/domain/technical documents.
- [UI_WIREFRAME_APPROVED_REFS.md](UI_WIREFRAME_APPROVED_REFS.md) — index of approved visual references and canonical links.
- [README_APPROVED_HTML.md](README_APPROVED_HTML.md) — policy and inventory for non-authoritative visual references.
- [UI_BUILD_PLAN_W0_W3.md](UI_BUILD_PLAN_W0_W3.md) — catch-up implementation plan for the UI of Waves 0–3.

The design system and approved-reference index are tracked locally for
repo-first operation. Per-screen raw HTML is still intentionally excluded;
the approved-reference index contains links and metadata, not executable
business behavior. Export one screen only when a dedicated `DOC-SYNC` task
needs it.
